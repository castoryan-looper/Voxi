        已有 Agent · OpenClaw

        可接入在家中电脑或云服务器运行的 OpenClaw。
        

        

        从 Voxi 云端访问此地址，凭据加密保存、不回显。内网、自签证书或没有公网入口时，使用“主动连接”。Gateway 凭据具有该实例的操作权限，仅接入你信任的 Voxi 服务。
        

        不需要公网 IP、端口映射或修改家中路由器。在运行 OpenClaw 的电脑上启动连接器并保持运行；电脑休眠后连接会离线，本机 Gateway Token 不上传。
        

        在 OpenClaw 所在电脑上连接
        1. 下载连接器（Python 3.10+，无需安装额外依赖）。
        2. 在下载目录运行以下命令，按提示输入连接密钥和本机 Gateway Token。
        关闭此页后无法读取连接密钥；丢失时删除未绑定的连接并重新创建。Voxi 使用自签证书时，启动命令另加 --ca 可信 CA 文件路径；请使用管理员已有的 CA，保持证书验证开启。
        

        

        首次启用与常见问题
        在 OpenClaw 机器上启用 Responses HTTP 接口，再重启 Gateway：
        openclaw config set gateway.http.endpoints.responses.enabled true
openclaw gateway restart
        “检测连接”只检查认证和接口，不会启动模型任务。显示正常后，绑定频道，再到该用户详情的“后台任务”提交一个只读小任务验证完整流程。工具权限、批准请求请在 OpenClaw 自身界面处理。当前 HTTP 接入没有把 OpenClaw 的批准窗口同步到 Voxi；停止等待后仍需核对远端任务。
