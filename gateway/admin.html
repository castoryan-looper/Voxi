      首次启用与常见问题
      在 OpenClaw 机器上启用 Responses HTTP 接口，再重启 Gateway：
      openclaw config set gateway.http.endpoints.responses.enabled true
openclaw gateway restart
      “检测连接”只检查认证和接口，不会启动模型任务。显示正常后，绑定频道，再到该用户详情的“后台任务”提交一个只读小任务验证完整流程。工具权限、批准请求请在 OpenClaw 自身界面处理。当前 HTTP 接入没有把 OpenClaw 的批准窗口同步到 Voxi；停止等待后仍需核对远端任务。
