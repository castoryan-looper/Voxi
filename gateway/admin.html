      首次启用与常见问题
      在 OpenClaw 机器上启用 Responses HTTP 接口，再重启 Gateway：
      openclaw config set gateway.http.endpoints.responses.enabled true
openclaw gateway restart
      “检测连接”只检查认证和接口，不会启动模型任务。显示正常后，绑定频道，再到“后台任务”提交一个只读小任务验证完整流程。工具权限、批准请求请在 OpenClaw 自身界面处理。当前 HTTP 接入没有把 OpenClaw 的批准窗口同步到 Voxi；停止等待后仍需核对远端任务。

        用户账户
        普通用户入口 ↗
        你当前是管理员，可以查看全部档案。普通账户只管理其绑定档案的资料、频道、OpenClaw、设备名称和任务。创建账户不会迁移已有设备与任务。
        

        创建普通账户
        一个档案对应一个登录账户；用户不能自行认领或改绑设备。新档案的设备归属由管理员在“设备管理 → 长期记忆”中绑定。
        

        登录名／类型用户档案状态操作
        停用或重置密码会撤销网页会话；不会删除资料、设备或任务，也不会代替取消正在运行的任务。
        

        登录会话最长 8 小时，退出登录后立即失效。每 5 秒更新连接状态。
