连接器在 OpenClaw 所在电脑上主动连接 Voxi；无需端口映射，本机 Gateway Token 不上传。电脑和连接器需要保持在线。

在 OpenClaw 电脑上连接

先启用接口并重启 Gateway：

openclaw config set gateway.http.endpoints.responses.enabled true
openclaw gateway restart
