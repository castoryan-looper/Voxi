接入管理

完成接入后，前往频道与助手绑定频道。快问和 Voxi Agent 可直接选择。

如何确认接入可用
  • 直连模型和聚合平台在保存或检测时，用你选的模型发送一次短文本请求，费用计入你的 API 账户。
  • Dify 应用先核对密钥、应用类型和输入配置。绑定频道后，用「我的任务」提交一条无副作用的测试输入，检查配置的输出。
  • OpenClaw 和 Muse Code先检测接口或连接器在线状态。绑定频道后，提交一个只读任务，例如概述测试项目的 README，再核对任务结果。

模型服务与 Dify 应用

接入后，可在「频道与助手」绑定频道。设备会播报及时返回的回复，也可以稍后说「读结果」，或在网页查看完整回复。

先启用接口并重启 Gateway：

连接 Muse Code

准备 Node.js 20+ 和已登录的 Muse Code。先在目标项目里运行 muse，完成登录及项目授权。把连接器放到单独目录，在该目录安装与 Muse CLI 1.4.15 配套的官方 SDK：

npm install @muse-code/sdk@1.4.15

将命令中的路径换成你要授权给 Muse Code 的项目目录。每个连接只运行一个连接器。

按提示输入连接密钥和本机 Gateway Token。 Voxi 使用自签证书时，请向管理员取得可信 CA 文件，启动命令增加 --ca 文件路径；保持证书验证开启。丢失连接密钥时，先解除频道绑定，再删除连接并重新创建。
OpenClaw 云端接入与任务确认
云端直连也需要启用 Responses 接口。使用有效 HTTPS 证书；内网或自签 OpenClaw 实例可在其所在机器运行主动连接器。“检测”只检查认证和接口，不运行模型任务。工具批准仍在 OpenClaw 自己的界面处理；停止等待后需核对远端是否仍在执行。
