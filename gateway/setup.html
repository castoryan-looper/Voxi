Voxi 设备管理

设置一次，按下就能对讲。配置直接写入设备。

通过 USB 连接

用数据线连接 ESP32，在 Chrome 或 Edge 中打开此页。网页通过 USB 直接配置设备，Wi‑Fi 密码和设备令牌不会发送到云端。

烧录前请先断开。首次设置不需要编辑 config.h。

设备热点登录

填写墨水屏 KEY 行显示的配置密码。

分级待机
按空闲累计时间逐级进入。关屏保留连接；断开云端后保留网络；休眠最省电，唤醒需要重新联网。USB 管理页连接期间保持唤醒。


没有 USB 时如何配置？
设备上同时按住 BOOT + PWR 约 3 秒，连接墨水屏显示的 VOXI 热点，在浏览器打开 http://192.168.4.1/，使用屏幕 KEY 登录。检测到 USB 主机时优先使用 USB，配置热点关闭。
