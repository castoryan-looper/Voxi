# Voxi Agent 改造交接 · 2026-11-08

用户确定：频道可自定义；提供开箱使用的 Voxi Agent，以及以后连接自有 OpenClaw 的本地/云端路径。后续明确要求先沿用当前 **codex-pocket-cloud**，做到可用；暂不接模型 API Key，在管理员后台提供填写入口。

## 实现与默认行为

Pocket Cloud 新增 `voxi_agent_store.py` / `voxi_agent.py`：SQLite 任务、用户频道覆盖、请求去重、独立 Codex app-server、用户目录、并发上限、审批/补充信息/中断/继续、事件派生终态、重启不重放。复用现有 MemoryStore 用户绑定、Whisper 转写与原生 appendSpeech 播报，不复用旧 Pocket 硬件任务线程。

Voxi 网关继续 MODE=pocket，新 `/api/admin/agent` 只代理固定 Docker 内网 `/voxi/agent`，继承现有管理员登录、CSRF 和 Origin 检查。新增 `/admin/agent`、`/admin/agent/tasks`、`/admin/agent/credentials`。无真实 API 调用；凭据 AES-GCM 加密保存、只返回配置存在标志，页面明确当前 Codex 执行器不会使用这些密钥。

默认 Agent 路由关闭以保留旧部署，管理员启用后 CH0=快问、CH1=Agent、CH2/3=未启用；支持用户自定义。后台状态不打断音频，主动“读结果”才播报摘要。新 MiniCam 固件显示 FAST/AGENT 和任务标记，录音跨重连保持 requestId。未改码率、缓存水位、11s 在途额度、APN 或证书。

## 验证与部署边界

已完成后端任务/权限/重启/审批等单测、原有语音回归、网关测试、真实浏览器经 HTTP 代理及 SQLite 的模拟执行流程、桌面/390px 手机截图检查。MiniCam 与 C6 固件编译通过；没有声称模型实际完成模拟任务，也没有刷入实机。

当前机器通过严格 SSH 校验访问服务器时提示没有已知 ED25519 主机密钥，未绕过。代码发布与服务器实际启用必须分别核对。升级后先运行 `deploy/check-agent.sh`，再在管理员页启用，先测一个后台文本任务，再测真实 PTT。详见 [运行说明](../VOXI-AGENT.md) 和 Pocket Cloud 的 `VOXI_AGENT.md`。

部署指令修正：用户在交互终端执行 `set -e` 后，容器 working_dir 的 `.git` 检查失败会直接退出会话。Pocket 自动发布器用 `git archive` 生成无 `.git` 快照，该路径不等于源码根。新增 `deploy/upgrade-pocket-agent.py` 优先调用已安装的快照发布器；普通 Git 部署才执行快进更新，缺失/不一致时停止且不删除配置或卷。用户已补回成功输出：Voxi revision 77883b5，engine=codex-pocket-cloud，4用户/0任务，enabled=false。这证明该版控制接口可达，尚不代表真实 Codex 任务或 PTT 已验收。

## 本轮频道与 OpenClaw 完善

用户指出旧四频道角色、默认频道和自定义频道重复，且缺少自有 OpenClaw 入口。本轮移除旧角色编辑入口，提示词页只编辑 FAST 通用风格；频道统一到“我的频道”，明确继承公共模板/独立保存/恢复继承，高级设置折叠服务参数和模板。

新增 `voxi_openclaw.py` 和网关 `voxi-openclaw.py`：云端 HTTPS 根地址+Token 接入；家中 Python 标准库连接器主动访问 Voxi HTTPS，Token 留本机。提供连接创建、一次显示连接密钥、下载与启动命令、只读检测、状态列表、用户所有权校验和绑定/删除。沿用 OpenClaw 既有角色/模型/工具，完成只认 Responses SSE 终态。实例/会话固定在任务提交和明确继续时，断线不重放，重复结果回传可确认。证书验证开启，不修改4G或固件；线协议对 OpenClaw 仍返回 AGENT，兼容现有设备。

本地完整流程通过：真实浏览器→网关→SQLite→受信 HTTPS→真实家中连接器→模拟 OpenClaw→任务结果。验证模板继承/恢复、连接检测不触发任务、只执行一次、390px 布局无溢出；所有外部 OpenClaw 执行为模拟，用户实例及真实 PTT 仍待验收。真实 OpenClaw 批准不映射到 Voxi；停止等待也不冒充远端已停止。连接器需手动保持运行，暂无系统服务安装或可靠本地结果发件箱。

本版仍是个人/小范围试用，不是商业多租户执行隔离。原生 OpenClaw 插件、独立托管工作器、商业 API 执行及收费账本仍为后续阶段。

## 4G 工作保持

参见 [当天 TCP 证据与设备状态](2026-11-08.md)。最新 11s 额度三分钟源完整性通过，但整轮约331s、6次耗尽、最大音频收包空档80.917s；小包期间仍有实际 TCP 重传/积压，恢复曾卡在3.98s/4s门槛。本次云端功能改造没有修复这项稳定性问题，不能把 Agent 功能验证当作 4G 通话验收。
