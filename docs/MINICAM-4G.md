# MiniCam ML307R 4G 联网

适用于 `zhengchen_minicam_20`（ESP32-S3 N16R8 / ST7789 2.0 英寸 / ES8388 / ML307R）。其他板型保留 Wi-Fi，不显示可用的 4G 选项。

## 切换

1. 用 USB 连接设备，打开本机设备配置页 `http://127.0.0.1:8788/`，刷新页面并连接串口。
2. 在“联网方式”选择“4G · ML307R”。普通 SIM 的 APN 留空，使用模组自动配置；专网卡按运营商要求填写 APN。当前不提供 APN 用户名/密码字段。
3. 保留已有网关、设备令牌和根 CA，点击保存。固件会回读校验配置后重启；重启后需重新连接 USB。
4. 等屏幕显示 4G 和 READY，主键单击开始录音，再单击发送。加减键短按调音量，长按换频道。

4G 模式不启动 Wi-Fi STA，不需要记住任何 Wi-Fi 网络。可随时在 USB 页选择 Wi-Fi 并保存恢复；切换不改变 eFuse 设备 ID 或云端长期记忆绑定。此版本只支持明确选择 Wi-Fi / 4G，不自动在两者间切换。

## 安全与传输

- ML307R 使用 UART1 TX47 / RX48，921600 baud。UHCI DMA 接收，64×512 字节内部 DMA 缓冲；解码后的 TCP 字节在 128KiB PSRAM 环形缓冲中交给 TLS。
- AT HEX 发送分片为 730 数据字节，避免超过模组 HEX 输入上限。逐包确认发送长度，错误或缓冲溢出会断开并走现有恢复逻辑，不静默跳过音频。
- TLS 由 ESP32 mbedTLS 实现，要求根 CA 链与主机名验证；4G 不允许保存关闭 TLS 的配置。模组时间用于启动后的证书有效期检查，无有效时间时等待校时，不跳过校验。
- 心跳先消费接收帧，再检查超时；收到有效语音/控制帧即可刷新存活，仅在空闲时发起 Ping。蜂窝 Pong 等待至少 15 秒，连续静默失败才断开；不把持续播放误判为离线。
- WebSocket 升级验证 `Sec-WebSocket-Accept`，客户端帧随机掩码，支持 Ping/Pong 和有限长度分片重组。每条业务消息上限 2048 字节，与现有网关协议一致。
- 蜂窝播放起播预缓冲为 6 秒，缓冲耗尽后按 2 秒步长自适应增加，最多 12 秒，并保留到后续轮次；已结束的短回复不必等满水位即可播放。可用环形缓冲约 24 秒 µ-law 音频。
- 回复协商 `mulaw8-24000`，有效载荷约 24KB/s，降低 HEX 串口带宽占用；旧网关未确认该格式时继续按其 PCM16 格式处理，不误解码。
- 录音使用现有本地缓存、完整性 CRC 和上传恢复机制；较慢的蜂窝上传可延后到录音结束后完成。录音上限仍为 20 秒。4G 不意味着上传延迟与 Wi-Fi 相同。
- 待机先断开 WebSocket，再令模组进入最小射频功能并停止 DMA，释放接收资源；按键唤醒后重新启动并入网。

## USB 诊断

`networkMode=cellular`、`wifiConnected=false`、`cellularDataReady=true`、`cellularTlsVerified=true` 和 `cloudReady=true` 共同表示正在通过 4G 安全连接云端。单独 `cellularRegistered=true` 只表示注册到运营商。

关注 `cellularStatus`、`cellularSignal`（CSQ，99 表示未知）、`cellularLastAt`、`cellularSocketError`、`cellularTlsError`、`cellularRxOverflows`。状态不输出令牌、IMEI、ICCID 或 SIM PIN。

## 验证记录

已验证 Wi-Fi 关闭时 4G / TLS / 网关 READY；使用不匹配根 CA 时返回 X509 证书验证失败，恢复正确 CA 后能重连。20 秒合成录音上传自检通过：960000 字节，采集 CRC 与发送 CRC 均为 2784024299，DMA 溢出为 0；本次蜂窝信号 CSQ 约 21–25，缓存尾段上传约 28 秒。后续重连已恢复 READY。真实语音录音 294240 字节完整上传，CRC 为 3271055425；回复收到并播放 32640 字节，接收/播放 CRC 均为 2844984367，完整性通过，重新缓冲及 DMA 溢出均为 0。心跳修正版短对话上传 33120 字节，回复 75360 字节完整播放，重新缓冲、DMA 溢出和扬声器写入错误均为 0。最终版本真实语音上板：录音 200160 字节完整上传，采集/发送 CRC 均为 3818492809；回复 492000 字节全部播放，接收/播放 CRC 均为 1652079427，零重新缓冲、零接收溢出、零扬声器写入错误，用户确认故事讲完且未掉线。该次连续在线超过 3 分钟。

长包解析区按最多 64KiB TCP 数据的 HEX 展开及头部预留 128KiB+256 字节 PSRAM，断线原因、最大包/行、缓冲峰值及状态查询延迟单独记录。SIM 状态查询失败不再直接视为 SIM 被拔出；明确的注册丢失或模组断开仍触发恢复。

验证边界：本机这张 SIM 的自动 APN 已实测；不同运营商、专网认证 APN、弱信号和 4G 待机唤醒仍需继续实机验证。本次故事播放通过不意味着任意蜂窝网络条件下都不会停顿。
