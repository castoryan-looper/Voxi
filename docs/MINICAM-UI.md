# MiniCam 暗色界面

240×320 ST7789 界面使用纯黑背景、深灰卡片、浅色文字和绿色/青色强调色。适用于标准音量＋录音及 GPIO11 改装 MiniCam 目标。

- 顶栏：VOXI、电量、电池图标；检测到充电时在电量左侧显示琥珀色闪电及 `CHG`，未检测到时不显示，检测不可用时显示 `?`。
- 连接栏：Wi-Fi 图标、4G 信号格、USB 图标。Wi-Fi 按实时 RSSI 点亮圆点和三层弧线，4G 按模组 CSQ 点亮四根信号柱；两路独立计算。未点亮的部分为暗灰色，断开连接时全灰并加斜线。USB 图标仍只表示 USB 连接。
- 主卡片：大号频道、网关连接指示，以及 READY、RECORDING、SENDING、WAIT AI、BUFFERING、PLAYING、OFFLINE 等状态。
- 下方：扬声器图标、音量进度、按住说话/松开发送等操作提示。USB/热点配置入口仍保留在底部，热点名称与设置密钥只在原有配置模式显示。
- 移除屏幕上的 MIC/TX/RX 字节、峰值和滚动 debug log；USB 管理页和诊断接口继续保留这些排障信息。

画面快照只保存可见状态；收包计数、日志内容变化不再单独触发全屏重绘。网络、频道、音量、录音和待机逻辑没有因这次视觉更新而改变。当前模组/公网 TCP 重传问题不属于本次界面更新的修复范围。

构建与烧录：使用 `zhengchen_minicam_20`，仅将对应应用写入 `0x10000`，保留 NVS、录音分区和原有联网设置。GPIO11 构建只适用于已改装主键的板子，不能误刷到当前标准板。

## 2026-11-07：真实信号档位与充电提示

Wi-Fi 分档：RSSI ≥ −60dBm 为四档，≥ −70 为三档，≥ −80 为两档，更弱为一档；未连接/无效读数为零。4G 分档：有效 CSQ ≥20/15/10 分别为四/三/两档，其余有效值为一档，未连接或 CSQ=99/无效时为零。这些是显示分档，不是射频功率百分比，也不表示吞吐量或 TCP 质量。4G 沿用现有约 10 秒轮询，Wi-Fi 随界面状态更新。

充电检测沿用厂家同款 MiniCam 代码的 GPIO4 **12 位原始 ADC** 阈值：>2300 进入充电态，≤2200 退出，区间内保留状态以避免闪烁。每秒取 8 次平均，同时采样 GPIO3 电池电压和 GPIO4 参考电压。修正此前拿校准后毫伏值与原始计数 2300 比较的单位错误，电池电压换算随充电/电池供电分支采用厂家的方法。USB 是否被电脑枚举不参与充电判定。

该 ADC 是厂家的充电/外接电源检测方式，没有单独读取充电 IC 的电流或终止信号；电芯已满时仍可能指示外接电源，不将 `CHG` 解释成已测得持续充电电流或已准确判断充满。电量百分比仍为板载电压估算。

USB status 增加 `wifiRssi`、`wifiSignalBars`、`cellularSignalBars`、`batteryChargeKnown`、可空的 `batteryCharging`、`batteryChargeSource`、`batteryReferenceRaw`、`batteryReferenceMv`、`batterySampleMv`，用于核对传感器来源及 UI 档位，不更改云端协议。

验证：标准版及 GPIO11 改装版构建通过；本机原生检查覆盖原始 ADC/毫伏单位、充电滞回及断开/未知信号。仅给 COM15 标准 MiniCam 写入应用 0x10000，Hash 校验通过。实机 GPIO4 原始计数约 2700、参考约 2.32V，`batteryCharging:true`；4G CSQ 23 对应四格，Wi-Fi 关闭时零格。临时切 Wi-Fi 后 RSSI −50～−53dBm 对应四档、4G 为零，Wi-Fi 云端 READY。随后已切回 cellular，4G/TLS/批量 Opus READY、屏幕刷新计数递增、无新错误，最终配置 revision 为 `2E39304F`。没有通过拔插实机电源验证充电提示的消失过程；该分支已做本机逻辑检查。原证书、令牌、APN、Wi-Fi 保存项保留；本次不需要云端部署。
