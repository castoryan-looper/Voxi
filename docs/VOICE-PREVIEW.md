# 音色选择与双语样音库

管理员在 `/admin/ai/voice` 选择服务默认音色，普通用户在 `/app/profile` 选择个人音色或跟随默认。选择 → 试听双语样音 → 单独保存；试听不会修改配置。FAST 和 Agent 播报都沿用设备当前音色，保存后重连或切换频道生效，不中断当前播放。

## 预先生成，长期保存

Pocket 启动后会自动准备全部 25 个候选音色，优先当前服务默认音色。每次只生成一个，并遵守现有语音会话上限；资源占满时等待，不关闭设备。生成复用现有 Codex 登录、WebRTC v3 和 appendSpeech，无需额外 API Key。首次准备会使用现有语音服务额度；后续点击已完成样音不调用模型。

成功样音保存到 Pocket 已有持久数据卷的 `runtime/voice-previews/<版本>/<音色>.wav`（路径相对于状态根目录）。版本由固定双语文本、协议、音频格式和候选目录计算。服务重启后复用成功文件，接着补齐未完成项；文本或协议变化才建立新版本目录。备份 Pocket 状态卷时一起备份样音。

浏览器点击试听只读已保存文件，不在 HTTP 请求中等待合成。缺失时提示后台准备，失败时单独提示；不会回退到其他声音。管理员页面显示已就绪数量、当前音色、资源等待、失败数量，选项标注可试听／待准备／生成中／生成失败。页面每5秒刷新进行中的任务；“补齐样音／重试失败”保留已成功音频，只重试失败和缺失项。普通用户能试听和查看就绪状态，不能发起全库重试。

## 统一双语内容

> 你好，我是 Voxi。很高兴和你一起，把事情做好。 Hello, I'm Voxi. Let's make good things happen together.

每段要求先中文、后英文，使用同一音色。所有候选提供相同文本，便于比较中文咬字、英文口音和自然度。目录元数据用 `previewLanguages` 表示样音内容，并将 `languageAssessment` 标为 `unrated`；这不是中文或英文的质量认证。未找到适用于当前全部25个v3候选的官方逐音色语言评分，不根据音色名称猜测“只适合英文／不适合中文”。生成成功也只证明取得完整音频，不代表语音识别或人工听感评估通过。需要在生产样音就绪后实际比较。

目录固定为 Codex CLI 0.163.0 `RealtimeVoicesList::builtin().v3` 的25个候选，默认Cove。其他协议、Speech API的声音与语言说明不直接套用到这里。兼容目录不等于当前账户支持所有候选；失败项需重试或检查服务。页面标明AI合成声音。网页与设备的网络压缩和扬声器会影响最终听感。

## 存储、权限与边界

独立临时 VoiceSession 不开麦、不加载个人记忆、不派发Agent任务、不启用研究工具。每段最多20秒、单次生成截止80秒；只有完整收到 audio_end 且音频有效才原子写入WAV。半成品、损坏文件和旧版本文件不作为可试听样音；关闭服务会取消生成会话并释放名额，已经完成的文件保留。失败记录一并持久化，重启不反复消耗失败音色的额度，管理员可主动重试。

网页只经登录后的 `/api/admin/voice-preview`、`/api/user/voice-preview` 访问固定内网接口，保留Cookie、CSRF、Origin和所有者校验。普通用户不能指定其他身份、任意文本或音频路径。全库准备仅管理员可操作；内网仍需bearer，Pocket公网ingress不开放此接口。共享的样音仅含固定产品文本。

服务接口版本为 `voicePreviewVersion: 2`；`deploy/check-agent.sh` 同时返回 `voiceLibrary` 的数量和运行状态，检查本身不生成音频。发布后自动开始准备，可在后台等待进度或重试。首次准备可能需要数分钟，实际受账号、网络和语音资源影响，未完成不宣称就绪。

个人音色优先于默认；旧配置迁移为Cove，旧用户继承默认；旧客户端保存文字偏好不会清除音色。此次不修改固件、4G码率或缓冲策略。音频目录可在回退时保留；若回到不支持voice字段的更旧版本，还需恢复相应配置备份。

## 验证

自动测试覆盖持久文件跨实例复用、批量补齐、失败记录和重试、取消回收、容量等待、无audio_end的半成品拒绝、损坏及旧版本隔离、权限和个人配置隔离。真实Chrome验收使用受控PCM，检查音频解码、状态、未保存试听、个人覆盖和390px布局。此前用户已确认云端单语真实试听可用；本次双语全库的实际声音质量需生产生成后试听。
