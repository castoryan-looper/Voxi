# 用户空间与管理员账户

| 类型 | 入口 | 权限 |
| --- | --- | --- |
| 管理员 | `/admin`，账户管理在 `/admin/users` | 全部档案与设备、服务开关、公共模板、系统配置；开通/停用普通账户及重置密码 |
| 普通用户 | `/app` | 自己的资料、FAST 偏好、频道、OpenClaw、设备名称、记忆/转写查看、任务和密码 |

角色由服务器决定，不接受客户端指定角色和所有者。普通用户没有全局用户选择器、系统密钥、全局模型、并发和设备改绑操作。管理员 Cookie 和用户 Cookie 分开，接口校验身份与所有者。

## 频道不能编辑的两种状态

频道服务关闭时，设备仍使用旧语音模式；可以先保存个人频道，但新路由和任务派发需要管理员开启。后台新增“开启频道服务”按钮。

管理员勾选“沿用公共频道模板”时卡片只读，点“单独配置此用户频道”进入编辑，修改后保存。普通用户的“我的频道”直接可编辑，保存建立个人覆盖；“恢复公共模板”清除覆盖。服务开关与模板继承是不同状态。

## 开通第一个普通账户

1. 管理员登录 `/admin/users`，填写登录名和初始密码，不提供默认密码。
2. 已有 MiniCam 用户时，选择它当前绑定的档案，保留现有设备、记忆、连接和任务。一个档案只允许一个普通登录账户。不要误选“新建用户档案”。
3. 没有档案时可新建称呼，初始没有设备；管理员再通过“设备管理 → 长期记忆 → 变更设备绑定”设置归属。用户不能凭知道设备编号自行认领。
4. 用户从 `/app` 登录，管理自己的资料、频道、OpenClaw 和任务。首次登录后建议在“账户安全”改密码。
5. 停用、管理员重置密码、用户改密码都会撤销该账户的全部网页会话；保留资料、设备和已接收任务，不代替取消任务。

原管理员账户和四个设备档案不会自动转换或创建普通登录。第一版由管理员开通，暂不支持自行注册、邮件找回、自主改绑或角色提升。

个人空间增加“我的语音音色”：支持跟随服务默认或选择个人音色，先收听持久保存的中英双语样音再保存，详见 [音色说明](VOICE-PREVIEW.md)。

## 存储与接口

普通账户文件为 `${ADMIN_STATE_FILE}.users`，正式部署为 `/state/admin.json.users`，复用已有 `gateway_state` 卷。只存带盐 scrypt 摘要、登录名、账户 ID、普通角色、启用状态和绑定的 Pocket 用户 ID；原子写入，POSIX 权限 0600。备份同时保留网关卷、Pocket 记忆/任务数据库及加密主密钥。

会话在内存保存，最长8小时，网关重启后重新登录。Cookie 为 HttpOnly/Secure/SameSite=Strict，修改操作校验 CSRF 和 Origin，登录有限流。密码不进入前端持久存储或日志。

网关 `/api/user/*` 验证普通会话后，将绑定档案作为 `actorUserId` 发送到固定 Docker 内网 `/voxi/portal`。客户端提交 `actorUserId`、`userId`、`role` 会被拒绝。Pocket 再校验任务、连接和设备归属；个人快照不复用管理员全量快照，不返回他人数据、系统指令或密钥。

`/api/admin/users` 继承已有管理员鉴权。新增内网管理员 `create_profile`，普通用户不能调用。FAST 偏好保存在用户命名空间，设备新建 FAST 语音会话时加载；OpenClaw 仍沿用自身角色。

## 验证与边界

已验证跨用户/管理员操作拒绝、密码摘要持久化、重置/停用撤销会话、退出清除个人表单、模板继承、桌面和390px界面。双用户真实浏览器经用户接口、SQLite、受信 HTTPS 和真实家中连接器，完成模拟 OpenClaw 任务往返。真实模型与设备仍需部署后验收。

本轮提供网页与数据接口的权限控制。现有托管 Codex 仍是个人/小范围试用环境；网页权限和用户目录不等于互不信任用户之间的工具执行隔离。公众多租户的独立执行工作器、开放注册和计费仍是后续工作。
