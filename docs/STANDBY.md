# 设备自动待机

默认空闲60秒进入待机。忙于录音、上传、等待AI、播放、提示音、缓存操作时不断延后计时；按键、旋钮、触摸和USB/网页配置请求重置计时。未配置设备及AP配网期间不自动待机。管理网页持续轮询属于活动，会保持唤醒；只插USB但未读取配置不会阻止待机。

## 状态与电源

工作→空闲计时→停止网络和显示任务→关闭外设→GPIO轻睡眠→按键/触摸唤醒→重新初始化→自动联网READY。

使用显式Light-sleep，不保持Wi-Fi/云端连接。CPU暂停、Wi-Fi关闭、音频codec静音并关闭、I2S收发停止。C6的TCA9554仅保留电池保持位，关闭显示/音频/功放电源；S3G关闭音频使能和功放，墨水屏powerOff保留画面；S3 AMOLED熄屏并让面板sleep-in、关闭功放和codec，保留触摸控制器及PMU供电用于GPIO21唤醒。保留唤醒与供电所需硬件，不能把整机所有电源断掉。

GPIO源按板型配置：C6 BOOT9/PWR2（外接旋钮16/17也可唤醒）；S3G BOOT0/PWR18与旋钮1/2；AMOLED BOOT0及触摸中断21。AMOLED PWR由PMU管理，本功能不重定义它的硬件电源行为。没有触摸硬件的墨水屏板仅支持按键/旋钮唤醒。第一轮唤醒输入不直接提交语音；恢复期间先等READY再说话。

唤醒后通过软件重启重新初始化驱动、DMA和TLS，网络配置、设备ID、音量和云端用户记忆不变，当前频道按原有启动默认值恢复。当前实时会话在待机时关闭，唤醒后由云端长期记忆恢复持久背景。云端显示离线是预期状态，不能通过云端页面远程唤醒。

网络任务会先确认断开，不在TLS读写中直接暂停；显示任务先完成当前刷新再关屏。遇到网络阻塞会延后待机；显示无法确认关闭时重启恢复。墨水屏正在刷新时，实际入睡可能晚于60秒。

## 诊断与验收

USB状态含standbyTimeoutMs/standbyIdleMs/standbyCount/standbyWakeCause/standbyLastError/standbyWakeInputGuard。USB状态读取会重置空闲计时，因此验证自动待机应关闭管理页串口连接，不连续轮询。

验收：保持配置完整、没有对话/网页操作，等待超过60秒。AMOLED应熄屏，云端连接应离线；按BOOT或轻点屏幕，等待自动联网后确认READY、再次按住录音。长故事播放超过60秒不能中途休眠。C6墨水屏保留旧画面，并不代表CPU仍在运行。需用电流表验证电池端待机电流，本实现不承诺未经测量的电流或续航数字。

单元测试覆盖60秒边界、长对话、用户输入/配置活动延后以及millis回绕。物理触摸唤醒须在AMOLED真机验收；三板分别编译，未接入的板子不能仅凭编译结果宣称硬件验收通过。

## 本次验证记录

当前接入的COM14设备为S3 AMOLED，已烧录待机版本并校验成功。USB状态回读超时60000ms、配置版本FDADCFC4保持不变；被动监听期间观察到USB进入断开状态。用户真机确认自动熄屏后触摸可重新亮屏并恢复READY。按键唤醒代码已配置，但本次尚未单独进行按键唤醒验收。C6/S3G完成编译，本次不在USB上，尚未烧录待机版；不能将AMOLED的触摸结果当作它们的硬件验证。

设计参考：ESP-IDF [Sleep Modes / GPIO Light-sleep](https://docs.espressif.com/projects/esp-idf/en/stable/esp32c6/api-reference/system/sleep_modes.html)。保留GPIO唤醒域并在休眠前停止无线外设，实际功耗仍以整板电池端测量为准。
