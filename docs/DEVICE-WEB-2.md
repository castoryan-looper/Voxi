# C6 Web-2 固件

参考 codex-pocket 02d6a7766fdf 的 Wi-Fi 策略和 BLE HID 旋钮实现。Voxi 是独立固件，更新 Pocket 仓库不会自动更新 Voxi。

- 最多记住 8 个 Wi-Fi；新网络保存后成为优先网络。断线后扫描并选择已保存网络，失败暂时退避；已连通时不主动换网。
- 已保存网络的密码留空即可复用。网页支持单独忘记网络，密码不回传网页。
- 蓝牙搜索后明确选择设备并配对；绑定成功后自动重连。旋转切换 4 个频道，PTT 使用设备 BOOT。蓝牙按压暂不映射 PTT。
- USB 和设备热点使用同一管理页面；本地 http://127.0.0.1:8788/ 刷新即可加载新版。
- 保存为 NVS blob，写入后逐字节回读比对，成功后显示配置编号并重启。重新连接 USB 后比对配置编号确认保留。
- 墨水屏合并重复状态、使用局部刷新，每 20 次变更做一次全刷。启动或定期全刷仍可能黑白闪烁；可通过网页运行时长和启动次数区分实际重启。
- TLS/WebSocket 在独立任务运行，音频及控制使用有界队列。错误时清空音频并重连，USB 配置循环继续运行。
- 页面诊断包含启动原因、运行时长、最小可用堆、连接阶段、最近错误。不同开机周期的启动次数不保证跨完全断电保留。

首次设置或此前保存未成功时，仍需填写 Wi-Fi、Voxi 设备令牌和 CA。Pocket 登录不等于设备已经有 Voxi 配置，也不会导入 Pocket 的服务器令牌。

验证：本地 C6 编译，管理页保存成功/失败/校验交互测试，网关与部署回归测试。真实旋钮配对、家庭网络自动切换和云端语音需在相应设备与有效配置下验证。

烧录修正：工厂分区固件不再写入 Arduino 默认的 boot_app0.bin（0xe000–0xffff），避免覆盖已有 NVS/PHY；保持原分区地址，避免迁移配置。
