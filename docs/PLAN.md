# Voxi 当前迭代计划

## 当前软件范围

- 微雪 C6：ES8311 单 I2S0 收发、TCA9554 音频/功放/电池保持、BOOT PTT、GPIO16/17 编码器、独立任务墨水屏显示。
- 设备：24kHz PCM16 单声道、10–20ms 音频块、40ms 起播缓冲、按下打断、松开生成、换台清会话、重连。
- 网关：mock/Realtime、频道人格、滤波、实时发帧、健康接口、连接限制与 30 分钟会话轮换。
- 云端：9443 WSS、根 CA、Compose、每分钟拉取、手动 pull hook、健康检查与网关镜像回退。
- CI：网关测试、镜像构建、C6 编译。服务器部署自带网关测试，不等待 CI 结束。

## 依次验收

| 阶段 | 操作 | 通过标准 |
|---|---|---|
| 首次部署 | 管理终端按 TENCENT-CLOUD.md 执行，放行 9443 | 本地与带 CA 的公网健康检查返回运行 SHA |
| 板载音频 | USB 供电、填配置、刷 firmware-c6 | 显示 READY，按住 0.3s 松开可听 mock 音 |
| 旋钮和屏幕 | EC11 接 16/17/GND | 四频道音高和显示一致，连续 50 次无卡死 |
| 真实语音 | 服务器 MODE=openai 与自己的 Key | 连续 20 轮中文，随时可打断，无旧音回流 |
| 自动更新 | 推送改动、等待 timer、检查 revision | SHA 更新，配置证书保留，设备重连 |
| 延迟声音 | 同轨录按键和扬声器，至少 30 轮 | 如实记录 P50/P95、打断、卡顿，再调优 |
| 便携 | 电池、音量、电源噪声、PWR 关机 | 1 小时稳定，实测续航 |

## 延迟预算

统计物理松键到首个 AI 语音，不把提示音计作首音。目标 P50 0.6–1.2s、P95 <2.5s、打断 <80ms，均待实测。预算约 15ms 消抖、5–30ms 局域网提交、400–1000ms 云端网络及生成、40–120ms 发帧和播放。网络与模型占主要不确定性，腾讯云地域按实际到语音服务的链路测量决定。

first_audio 日志只测网关收到松键到首帧发出，不含实体按键和设备播放。冷启动、换台、热会话分别统计。维持连接、边说边传、松键提交和短句回复优先。

## 待完成的真机工作

- 确认电源保持/PA、ES8311 左槽、输入增益、屏幕 D67 波形和硬件批次。
- PWR 长按关机、音量、短提示音与故障反馈；当前保留 PWR 不处理。
- IP SAN 证书校验、NTP 失败、断网恢复和电池续航。
- 模型会话轮换会丢上下文；长记忆和独立频道记忆后续再加。
- 回退暂时只覆盖网关镜像；补完整版本回退与磁盘管理。
- 单实例重建短暂断线；不做零停机或 ESP32 OTA。

旧 firmware/ 是 S3 外接 INMP441/MAX98357A 历史原型，当前 C6 无需外接这些模块。

## 用户身份与长期记忆：产品决策（2026-11-04）

当前确定采用「一台设备固定绑定一个人」。后续用户档案、对话历史和长期记忆按设备绑定的用户归属；本阶段不做声纹登记、自动辨认说话人或多人切换。此处是产品范围约定，并不表示用户绑定与长期记忆功能已经实现。
